# SEO Optimization Toolkit

This directory contains a comprehensive SEO optimization toolkit that integrates four specialized tools into a unified workflow. See `use.md` for the complete user guide.

## Tools in This Toolkit

1. **Google Search Console MCP Server** (`mcp-gsc`) - Data collection and performance analytics
2. **OpenSEO** - AI-native SEO intelligence with competitive analysis
3. **GEO Optimizer Skill** - Generative Engine Optimization for AI citation readiness
4. **Claude SEO** - Universal SEO auditing with 26 sub-skills and 19 agents

## Key Concepts

This toolkit addresses both traditional search rankings and emerging AI engine visibility through:
- **Data-driven optimization** (GSC performance data)
- **AI-native intelligence** (OpenSEO competitive analysis)
- **Generative Engine Optimization** (GEO citation readiness)
- **Comprehensive technical auditing** (Claude SEO)
